# SmartBox Measure v0.3.0 — Live Depth Measure (ทุกรูปทรง)

วัด **ยาว × กว้าง × สูง แบบสด** จากกล้องมือถือ พร้อมวาดกล่องสี่เหลี่ยมครอบวัตถุ ไม่ต้องถ่ายภาพ
และยังมีโหมดถ่ายภาพ TOP/SIDE จาก Phase 1 (โหมดนี้ **ไม่คำนวณขนาด** เพราะไม่มีข้อมูลระยะลึก)

## ข้อเท็จจริงสำคัญ
- ขนาดจริงต้องมี Metric Scale: โหมดวัดสดใช้ **WebXR Depth Sensing** → ใช้ได้เฉพาะ **Android Chrome + ARCore ที่รองรับ Depth**
- **iPhone Safari ไม่มี WebXR** → วัดสดไม่ได้ (ทางที่ถูกต้องบน iPhone คือแอป native ARKit + LiDAR)
- ระบบไม่แสดงตัวเลขหากไม่มีข้อมูลระยะลึก; ผลที่ได้เป็น **Estimated** เสมอ ไม่ใช่ Verified
- เป้าหมาย ±5 mm **ยังไม่ได้พิสูจน์** ต้องทดสอบเทียบเครื่องมือมาตรฐานบนเครื่องจริง (Phase 6)

## รูปทรงที่รองรับ (จำแนกอัตโนมัติ หรือเลือกเองในหน้าวัดสด)
| รูปทรง | ค่าที่รายงาน | วิธีวัด |
|---|---|---|
| กล่องสี่เหลี่ยม | ยาว/กว้าง/สูง | min-area rectangle ของผิวบน + สูงจาก median ผิวบน |
| ซองไปรษณีย์ | ยาว/กว้าง/หนา | เหมือนกล่อง แต่ตรวจแยกวัตถุบางด้วย median ต่อเซลล์ (หนาต่ำสุดที่แยกได้ ~1 ซม.) |
| ถุงพัสดุ | Max Length/Width/Height | กล่องครอบของจุดทั้งหมด (Maximum Extent) |
| ทรงกระบอก | ยาว/รัศมี/เส้นผ่านศูนย์กลาง | ตั้ง: พื้นที่ผิวบนกลม; นอน: ความยาวจากสันบน, เส้นผ่านศูนย์กลางจากความสูง |
| รูปทรงอิสระ | Max Extent X/Y/Z + ปริมาตร | กล่องครอบตามแกน OBB + ปริมาตรใต้ผิวบน |

**การจำแนกอัตโนมัติเป็นฮิวริสติก** ใช้ความเรียบของผิวบน สัดส่วนเติมเต็มของฐาน ความกลมของผิวบน และโปรไฟล์ตัดขวางครึ่งวงกลม
ใช้เสียงข้างมาก 9 เฟรมกันกระพริบ ถ้าเดาผิดให้เลือกรูปทรงเองจากเมนูในหน้าวัดสด

**การเดินรอบวัตถุ (ถุง/ทรงกระบอก/อิสระ):** มองด้านเดียวไม่เห็นผนังด้านหลัง ขนาดจะขาด ระบบจึงสะสมจุดจากหลายมุมในพิกัดโลกของ ARCore
(HUD แสดง % มุมที่เก็บแล้ว; ปุ่ม "เริ่มเก็บมุมใหม่" ล้างข้อมูล) ปริมาตรของถุง/อิสระเป็น "ค่าประมาณเชิงขอบบน" (สมมติทึบถึงโต๊ะ)

## อัลกอริทึม (src/geometry, src/depth)
1. Depth map (WebXR cpu-optimized) → Point Cloud พิกัดโลก (`pointCloud.js`)
2. ระนาบโต๊ะแบบจำกัดด้วยแรงโน้มถ่วง: histogram ความสูง + median refine (`plane.js`)
3. แยกวัตถุ: median ต่อเซลล์ + connected components เลือกกลุ่มกลางภาพ จำกัดรัศมี 0.8 ม. (`dimensionCalculator.js`)
4. ตัด flying pixels (ขอบ depth เบลอ) + จำแนก/วัดตามรูปทรง (`shapeMeasure.js`, `obb.js`)
5. สะสมหลายมุม (`ObjectAccumulator`) และกรองความนิ่งด้วย median 12 เฟรม (`validation/qualityGate.js`)
6. วาดกล่องครอบด้วย WebGL บนภาพกล้อง (`render/boxRenderer.js`, `depth/webxrMeasure.js`)

## ผลทดสอบจำลอง (`npm test`, 19 ข้อ)
ฉากสังเคราะห์ (noise 4 mm + เบลอขอบ), คลาดเคลื่อน (มม.) ของค่าที่รายงาน:
- กล่อง / ซอง / ทรงกระบอก (ตั้ง, นอน): ส่วนใหญ่ ≤ ~12 มม.
- ถุง / อิสระ มองด้านเดียว: ฝั่งตรงข้ามขาดได้ถึง ~4 ซม.; หลังเก็บ 3 มุมเหลือ ~1 ซม.
**นี่คือการทดสอบคณิตศาสตร์เท่านั้น ไม่ใช่ความแม่นยำบนเครื่องจริง** ค่าชดเชยขอบจูนจากโมเดลเบลอจำลอง ต้องปรับใหม่กับข้อมูลเครื่องจริง

## วิธีใช้งาน
```bash
npm install
npm test            # ทดสอบ geometry
npm run dev         # https://<IP>:5173 บน Android Chrome (Wi-Fi เดียวกัน)
```
บนมือถือ: กด **เริ่มวัดแบบสด** → อนุญาตกล้อง/AR → เล็งวัตถุบนโต๊ะให้อยู่กลางจอ ห่าง ~40–70 ซม. เห็นโต๊ะรอบวัตถุ
เอียงมองจากด้านบนราว 45–60° → รอสถานะ "นิ่งแล้ว" → กด **บันทึกค่า** → ปิดโหมดแล้วดูในส่วนผลการวัด

## ข้อจำกัดที่ทราบ
- ยังไม่ได้ทดสอบ WebXR บนเครื่องจริง (ทิศแกน v ของ depth มีการตรวจอัตโนมัติ แต่ต้องยืนยัน)
- ต้องมองเห็นโต๊ะรอบวัตถุ (ระนาบรองรับต้องเป็นแนวนอน); วัตถุที่บางกว่า ~1 ซม. ตรวจไม่พบ และซองบางความหนาไม่น่าเชื่อถือ
- วัตถุที่เกือบเต็มจอ/ชนขอบภาพจะไม่รายงานตัวเลข (CLIPPED)
- ปริมาตรถุง/อิสระเป็นขอบบน ไม่ใช่ปริมาตรจริง; วัตถุกลวงหรือมีช่องใต้วัตถุไม่รองรับ
- วัตถุโปร่งแสง/สะท้อน/ดำเข้ม ทำให้ depth ผิดพลาดได้; วัตถุหลายชิ้นติดกันจะถูกรวมเป็นชิ้นเดียว
- iPhone Safari ไม่มี WebXR จึงวัดสดไม่ได้
